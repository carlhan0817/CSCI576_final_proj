## What Phase 2 Does

Phase 2 is the **signal processing and machine learning stage** of the CSCI 576 multimodal video segmentation system. It reads the deterministic, time-aligned artifacts generated by Phase 1 (`meta_raw.json`, `audio_processed.wav`, `transcript.json`, and the `frames_cache/` directory) and extracts mathematical features to detect semantic and structural boundaries.

All features are saved as strict Pydantic-validated JSON artifacts in the `workspace/<stem>/features/` directory. These artifacts serve as the sole input for the Phase 3 Late Fusion engine.

| Modality | Input (Phase 1) | Output (Phase 2) | Core Technology | Purpose |
|---|---|---|---|---|
| **Text** | `transcript.json` | `text_features.json` | `all-MiniLM-L6-v2` | Topic boundary detection via sequential cosine similarity. |
| **Visual** | `frames_cache/*.jpg` | `visual_features.json` | OpenCV & CLIP ViT-B/32 | Hard cut detection and zero-shot semantic scene classification. |
| **Audio** | `audio_processed.wav` | `audio_features.json` | Silero VAD | Precise timestamp detection of human speech vs. background noise. |

File-by-File Guide
backend/pipeline/schemas.py (Phase 2 Additions)
Extends the Pydantic v2 data contracts to enforce strict schemas for the output JSONs.

* TextFeatures: Contains a list of TextFeatureSegment objects, noting the similarity_to_next (float) and a boolean is_potential_boundary.

* VisualFeatures: Contains a list of VisualFrameFeature objects, tracking hist_diff_to_previous, a boolean is_hard_cut, and a dictionary of clip_labels with probability scores.

* AudioFeatures: Contains a list of AudioFeatureSegment objects, providing exact start and end timestamps for when is_speech is true.



backend/pipeline/features/text.py
Analyzes the transcript to detect when the speaker changes topics.

* Model: Uses sentence-transformers/all-MiniLM-L6-v2. It maps sentences to a 384-dimensional dense vector space.

* Mechanism: Calculates the Cosine Similarity between Sentence N and Sentence N+1.

* Boundary Logic: If the similarity dips below DEFAULT_SIMILARITY_THRESHOLD = 0.35, it flags the segment as a potential boundary. (Note: This hard threshold is a baseline; Phase 3 will override this dynamically via the TOML config).

backend/pipeline/features/visual.py
Acts as the "eyes" of the system, evaluating structural and contextual changes on screen.

* Structural Cuts (OpenCV): Calculates a 3D HSV Color Histogram for each frame and compares it to the previous frame using cv2.compareHist (Correlation). A difference score above DEFAULT_CUT_THRESHOLD = 0.6 triggers is_hard_cut = True.

* Semantic Context (CLIP): Passes each frame through openai/clip-vit-base-patch32 to perform zero-shot classification against custom labels: ["a presentation slide", "a person talking to a camera", "a screen recording of software", "a blank screen"]. Returns a softmax probability distribution.
